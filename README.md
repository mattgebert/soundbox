# Soundbox

This is a demo app to self-host music and create nice music visualisations, powered by the HTML5 Canvas element.

Built with

- Nodejs + Vite
- React
- MUI Material
- TypeScript
- Docker

It also demonstrates the use of CI tools such as

- Commitizen
- ESLint
- Prettier
